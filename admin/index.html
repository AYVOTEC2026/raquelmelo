Configurar o acesso

Feito uma vez. O painel guarda um token do GitHub protegido pela senha da Raquel: sem a senha, ninguém consegue usar o token.

  1. No GitHub da conta AYVOTEC2026, abra Fine-grained tokens › Generate new token.
  2. Nome: Painel de fotos Raquel. Validade: 1 ano.
  3. Em Repository access, escolha Only select repositories e marque raquelmelo.
  4. Em Permissions › Repository permissions, deixe Contents como Read and write. Nada mais.
  5. Gere o token, copie e cole abaixo.

Fotos do site
