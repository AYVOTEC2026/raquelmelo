Entrar no painel

Aqui você muda as fotos, os vídeos, os textos e os horários do site. Digite a sua senha.

Configurar o acesso

Feito uma vez. O painel guarda um token do GitHub protegido pela senha da Raquel: sem a senha, ninguém consegue usar o token.

  1. Logado no GitHub da conta AYVOTEC2026, abra este link. Ele já vem com o nome, a validade de 1 ano e a permissão Contents: Read and write.
  2. Em Repository access, escolha Only select repositories e marque raquelmelo (só ele).
  3. Toque em Generate token, copie o token e cole abaixo.

Fotos e vídeos

Toque numa foto para trocar, mudar de lugar ou remover. Quando terminar, toque em Publicar no site. Espaço sem foto some do site sozinho.

Textos do site

Toque numa parte do site para abrir e mudar os textos. Campo vazio some do site. Quando terminar, toque em Publicar no site.

Perguntas frequentes

Adicione, mude a ordem, edite ou remova perguntas. Quando terminar, toque em Publicar no site.

Contato e horários

WhatsApp, Instagram, endereço e horários aparecem em vários lugares do site: mude aqui e tudo se atualiza junto.
